📌 About the Project

This project is a simple addition calculator developed using the Python programming language.

The program takes two numbers from the user and displays their sum. Thanks to the while loop, the program continues running and allows the user to perform new calculations.

🚀 How It Works

When the program starts, the user is asked to enter two numbers. The two numbers are added together and the result is displayed on the screen.

💻 Technologies Used

Python 3

input() function

int() type conversion

while loop

Addition (+) operator

▶️ How to Run

To run the Python file:
